# README
## Datasets

### Lichess Elite Database
The [Lichess Elite Database](https://database.nikonoel.fr/) was created by Lichess account nokonoel and can be downloaded from: https://database.nikonoel.fr/

This projecy uses the games included in the database from February 2025, which consists of $256430$ games in total.

### Puzzle Dataset
The puzzle dataset used for this project is part of the ChessBench dataset. The Puzzle dataset was created by Ruoss et. al. as part of a larger project. The puzzle dataset can be found on the repository for the project on [github](https://github.com/google-deepmind/searchless_chess?tab=readme-ov-file#puzzles): https://github.com/google-deepmind/searchless_chess
